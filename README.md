# 문자열 덧셈 계산기

## 문제 및 조건
입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현했습니다.
쉼표(,) 또는 콜론(:)을 구분자로 가지고 커스텀 구분자(//)를 지원합니다.

### 기능 목록
- [] 문자열 입력
- [] 문자열에서 숫자 추출
- [] 커스텀 구분자
- [] 문자열 숫자 계산
- [] 결과 출력
- [] 예외 처리
  -  [] 기본 구분자 이외의 구분자
  -  [] 커스텀 구분자 등록 실패

### 프로그램 동작
1. '덧셈할 문자열을 입력해 주세요.' 문구 출력
2. 구분자와 양수 입력
   2-1. 커스텀 구분자 입력 ('//' 와 '\n' 사이의 문자)
3. '결과: ' 문구 뒤 양수들의 덧셈 결과 출력
